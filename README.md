# School Management for Odoo 19

Odoo 19 addon for Kenyan schools (CBC and 8-4-4): admissions, students and guardians, classes and timetable, attendance, exams and report cards, fees on Odoo Accounting, parent portal, announcements and SMS.

The addon is in [`school_management/`](school_management/). See its [README](school_management/README.md) for installation and setup.
